Live Activity

The running session outside the app: Lock Screen, Dynamic Island and the Duo outer display. It shows one thing — the task and its time — and offers the same two actions as the chip. It starts with Begin and ends when the session does; it never starts on its own.

v1.1 · not in launch scope
{{ themeLabel }}
Surface
Deep background in both appearances, onDeep text — the same surface as the focus screen, so the Live Activity reads as that screen, shrunk. No glass: it isn't an action layer inside the app.
Time
A system timer text counting up from the start, so it stays live without updates. The estimate shows as a thin bar; past it the bar stays full and the line says so in words — no red, no flashing.
Actions
Pause/Resume and Finish, as App Intent buttons. Finish is the one terracotta fill (the dark-appearance terracotta, which holds contrast on deep). Finish opens the app's finish sheet; nothing is logged from the Lock Screen without it.
