# Design handoff: App Store pictures

The real app, captured with a curated dataset (`-JamaalStoreShots`), in Light appearance. **The system status bar, the iPadOS window grip and the Duo's status pill have been taken out**; please do not draw one back in. Nothing here is composed: turning these into the store slides is the job in [the brief](../../../docs/design/app-store-screenshots-brief).

Regenerate with `capture-ios.sh`, `capture-ipad.sh`, `capture-mac.sh` and `capture-duo.sh` (the Duo poses are set by hand in Device Hub), then `prepare-handoff.py`.
